Balanced Excitatory–Inhibitory Network

10³ to 10⁵ cells · ms

A balanced network couples many integrate-and-fire neurons, four excitatory for every inhibitory one, through sparse random connections. Each neuron receives a large excitatory input and a large inhibitory input that nearly cancel, so its mean drive stays below threshold and its spikes are triggered by the fluctuations that remain.

The raster shows the spikes of the network over time, with the population rate beneath it, and the right panel follows the excitatory, inhibitory and net input of one neuron. Change the relative strength of inhibition g and the external drive, and take g below four, where inhibition can no longer balance excitation.

With strong inhibition the network settles into an asynchronous irregular state, in which each neuron fires at seemingly random times, with an irregularity close to that of a random process, while the population rate stays nearly flat. With weak inhibition excitation runs ahead: rates climb towards the limit set by the refractory period, and every neuron fires almost like a clock.

Ask yourself
Every neuron here is deterministic and only the external input is random, yet each neuron fires irregularly. Where does the irregularity come from?
Equations
τ dVj/dt = −Vj + τ Σi Jij Σk δ(t − tik − D) + external Poisson input
Jij = J for excitatory i,   Jij = −gJ for inhibitory i
if Vj ≥ θ: spike, Vj ← Vr, refractory for τref
400 neurons (320 excitatory, 80 inhibitory), connection probability 0.1, J = 1 mV, θ = 20 mV, Vr = 10 mV, τ = 20 ms, τref = 2 ms, delay D = 1.5 ms. External drive is given relative to the rate that would just bring a neuron to threshold.
Pseudocode
for each time step dt:
    for each neuron j:
        V_j decays towards 0 and receives external Poisson kicks of size J
        add the spikes arriving now from presynaptic neurons i:
            +J for excitatory i,  −g·J for inhibitory i
        if V_j ≥ θ: record a spike, V_j ← V_r, hold it for τ_ref
    schedule this step's spikes to arrive after the delay D
